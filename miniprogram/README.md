# 时光印记 · 微信小程序

和网站共用同一套水印绘制代码（`src/services/watermark*.ts`、`src/data/templates.ts`、`src/utils/date.ts` 等），改一处，网站和小程序都会生效。

## 目录

```
miniprogram/
  project.config.json   开发者工具项目配置（代码根目录指向 dist/）
  src/                  小程序源码（TypeScript + WXML/WXSS）
    lib/                选图、EXIF、绘制、保存、本地存储
    pages/home          首页：模板库 + 选照片
    pages/editor        编辑页：预览、模板、文字、样式、保存/分享
  dist/                 构建产物（不提交，由命令生成）
```

## 开发

1. 在仓库根目录安装依赖：`npm install`
2. 构建并监听修改：`npm run mp:dev`（只构建一次用 `npm run mp:build`）
3. 打开微信开发者工具 → 导入项目 → 目录选 `miniprogram/`，AppID 填你自己的。
4. 手机预览：开发者工具里点「预览」扫码，或「真机调试」。

其他命令：

- `npm run mp:check`：TypeScript 类型检查
- `node scripts/check-miniprogram.mjs`：用模拟的 `wx` 环境跑一遍导入、编辑、保存流程（需先 `mp:build`）

## 上线前需要在小程序后台做的事

1. **用户隐私保护指引**（设置 → 服务内容声明）：声明会使用「选中的照片或视频信息」「相册（仅写入）权限」和「选择的位置信息」，用途分别填「给照片添加日期水印并保存」「在地图上选择照片的拍摄地点」。不声明的话，选图、保存到相册和地图选点会直接失败。
   - 地图选点用的是 `wx.chooseLocation`，已在 `app.json` 的 `requiredPrivateInfos` 里声明。如果后台「开发管理 → 接口设置」里有「地理位置」接口需要开通，开通 `wx.chooseLocation` 即可（不需要实时定位）。
2. **服务类目**：选「工具 → 图片/音视频」一类即可，个人主体也能选。
3. **网页版地址**：把网站地址填进 `src/lib/config.ts` 的 `WEB_URL`，首页底部会出现「复制网址」。小程序不宣传自动读取，引导需要自动读取时间地点的人去网页版。
4. **手写字体（可选）**：「旅行明信片」「拍立得」默认用手机自带的衬线字体。想要手写效果：
   - 把字体文件（TTF 或 WOFF，WOFF2 在旧版 iOS 上不兼容）放到你的 HTTPS 网站上；
   - 在后台把该域名加入 downloadFile 合法域名；
   - 把地址填进 `src/lib/config.ts` 的 `HAND_FONT_URL`。
   字体文件约 3 MB，超过主包 2 MB 的上限，所以不能直接打进包里。

## 和网站版的区别

| 功能 | 网站 | 小程序 |
| --- | --- | --- |
| 10 款模板、字体/颜色/位置/衬底调整 | ✓ | ✓（「相机参数」换成「生活信息条」，因为微信会去掉机型信息） |
| EXIF 拍摄时间、相机参数、GPS 匹配城市 | ✓ | ✓（自带轻量 EXIF 解析） |
| 五种日期格式、地点/事件同步到全部 | ✓ | ✓ |
| 宝宝月龄 | ✓ | ✓ |
| 保存 | 下载 JPEG/PNG、ZIP、PDF | 保存到相册（单张/全部），发给朋友 |
| 相纸尺寸排版（3/5/6 寸，300 DPI） | ✓ | ✓（样式 → 冲印尺寸） |
| 地图选点 | 在线地址解析 | ✓（腾讯地图选点，填地点和经纬度） |
| 成长拼图 / 今年·去年对比 | 暂无 | ✓ |
| 在线地址解析（高德/OSM） | ✓ | 暂无（需配置合法域名） |
| HEIC | 浏览器内转换 | 由微信选图时处理 |

## 需要真机确认的地方

这些只能在手机上验证，开发者工具的模拟器结果不一定准：

- **照片信息（已真机确认）**：微信在把照片交给小程序之前会去掉大部分信息，小程序无法绕过：
  - iPhone（iOS 27、微信 8.0.80）：重新编码成不带任何拍摄信息的 JPEG，日期、地点、机型都没有。编辑页会提示「点这里选日期」，多张可一次填好。
  - 安卓（小米，微信 8.0.80）：保留拍摄时间和曝光参数（焦距、光圈、快门、ISO），但删掉了相机品牌型号和 GPS 经纬度。日期能自动读出，地点需要手填（可「同步全部」）。
- **竖拍照片方向**：如果手机解码图片时没有按 EXIF 自动旋转，代码会自己转正。请用竖着拍的原图试一下。
- **地图选点**：开发者工具里地图可能是空白，需要在手机上确认能打开地图、搜索地点。
- **成长拼图内存**：每张照片先缩到 1000 像素再拼，12 张也只占几十 MB；旧手机上请试一下 12 张的情况。
- **大图导出**：导出图片长边最大 3200 像素，失败时自动降到 2048。旧手机可能更慢。
- **字体效果**：画布用的是手机系统字体（iOS 苹方、安卓系统黑体），字形和网站上会略有差别。
