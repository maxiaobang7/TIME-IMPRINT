# 隐私与数据处理

- 照片通过浏览器文件选择器读取，在设备上解析 EXIF、转换格式和生成水印；本项目没有照片上传接口。
- 默认的离线地点匹配在本地运行。选用 OSM / 高德时，经纬度会发送至所选地图服务；第三方还可获知连接的 IP 等网络信息。
- 宝宝昵称、生日、样式偏好、地图设置和地点记忆使用当前浏览器 localStorage。地点记忆包含经纬度、手动名称、区域键和更新时间。清除网站数据可移除这些本地信息。
- 高德 Key 由用户填写，保存在浏览器中，并随请求发往高德。纯前端无法保密共享 Key，维护者不应将自己的生产 Key 写入仓库。
- 当前照片与编辑结果主要存在页面内存中，不提供云端同步或可靠的刷新恢复。导出的文件由用户自行管理。
- 网站本身未集成广告或统计 SDK；托管平台仍可能产生常规访问日志。未来如增加广告、分析或其他服务，需要同步更新此说明。
- 本文描述当前代码行为，不代表第三方服务的隐私承诺。
