# 时光印记使用说明

## 1. 添加照片

首页选择喜欢的模板，点击“选择照片，开始制作”。可选择单张或多张照片，导入后进入相册工作室。默认模板是轻盈角标；下方缩略图可切换或移除照片，也可继续添加。

支持常见 JPEG、PNG，以及通过本地转换处理的 HEIC / HEIF。不同设备对 HEIC 的编码支持有差异；转换失败时可先使用 JPEG 原片。

多张照片会逐张处理并显示进度。损坏或不支持的图片会单独列出并跳过，其余照片照常导入。点击“取消后续处理”后，当前照片处理结束即停止，已完成的照片仍会保留。

## 2. 选择模板

| 模板 | 适用场景 |
| --- | --- |
| 轻盈角标 | 不遮挡主体的时间、地点记录 |
| 经典日期 | 简洁日期留念 |
| 时光留白 | 白色边框与整洁信息排版 |
| 成长日记 | 宝宝昵称、月龄与成长事件 |
| 纯白画廊 | 清爽的摄影作品展示 |
| 旅行明信片 | 地点、手写寄语、落款和邮戳 |

在“模板”页展开“调整样式与位置”，调整可用的字号、颜色、透明度等。部分边框模板采用固定排版，不提供自由移动水印。

“恢复默认样式”只还原当前模板的样式，不删除照片、不清空文字，也不重置宝宝资料。

## 3. 编辑文字

在“文字”页核对拍摄时间、拍摄地点、经纬度和记录事件。时间、地点、坐标、宝宝月龄可按需显示或隐藏。旅行明信片还可修改手写寄语和落款，清空即可隐藏对应文字。

在“设置”中填写宝宝昵称与生日，月龄会随“拍摄时间”的修改同步计算，没有 EXIF 的照片也能手动补填。支持 2026-09-23、2026.09.23、2026/09/23、2026年9月23日，以及可选的时分。日期为空、无效或早于宝宝生日时不显示月龄；自定义日期文字仍保留，不会套用原始 EXIF 的旧月龄。新用户的宝宝档案默认为空。

没有 EXIF 的照片不会凭空产生真实时间或 GPS。iPhone 相册内能看到的信息，也不一定包含在浏览器收到的文件中。建议使用原始照片，并在导出前核对信息。

## 4. 地点匹配

默认“本地离线”根据 GPS 匹配附近的城市中心，仅供省市参考；边界附近、覆盖不足或国外照片可能不匹配或不准确。没有 GPS 时只能手填地点。

为有坐标的照片手动填写地点后，浏览器会记忆，只自动使用 200 米范围内最近的记录。相距更远时会重新解析，不再沿用同城其他景点的旧名称。GPS 有误差，附近地标仍请核对。设置中的“清除位置记忆”可删除这些记录。

可选 OSM / 高德联网服务会向第三方发送经纬度，可能受配额、网络和服务政策影响；高德需要用户自己的 Key。默认离线处理无需 Key。

## 5. 选择尺寸

“相纸”页可选择原始比例，或 3 / 5 / 6 寸尺寸，设置完整保留、居中裁切及安全边距。想保留全部画面请选择“完整保留”。固定尺寸可能增加留白；居中裁切会裁掉部分内容。网站不直接连接打印机。

## 6. 保存与批量导出

- 电脑 / 安卓：下载当前图片，或在更多选项中导出 PDF、批量 ZIP。
- iPhone Safari：点击“保存到相册”，等待生成图片。支持系统文件分享时，点击“打开系统分享”，再选择“存储图像”等系统选项；也可以长按图片保存。
- 如果浏览器不提供相册保存选项，可用“下载到文件”，随后在“文件”App 打开并通过系统分享保存。

系统菜单名称随 iOS 版本变化。网站无法绕过系统交互自动写入相册，取消分享也不代表已经保存。HTTPS 对系统分享和添加主屏幕等能力很重要。

批量导出前核对每张照片内容；当前模板样式可以应用到整批照片。预览最长边为 1200 像素，导出仍按所选相纸尺寸或原有自由尺寸规则生成（自由尺寸最长边不超过 3200 像素）。PDF/ZIP 逐张生成并显示进度；取消后不会下载不完整的文件，原有照片和编辑内容会保留。最终 ZIP/PDF 本身仍会占用内存，手机建议分批处理。

## 7. 常见问题

**刷新后照片还在吗？** 照片不作为项目存入本地数据库；刷新或关闭页面可能失去当前编辑，请及时导出。部分偏好和地点记忆保存在当前浏览器，清理网站数据后会消失。

**照片会上传吗？** 照片、EXIF 读取和水印合成都在浏览器处理；默认离线地点匹配不发送坐标。主动选择联网解析时只查询坐标，不上传照片。

**首次断网能用吗？** 不行，需要先加载网站。生产版本会缓存已经访问过的资源，但未缓存的字体或转换模块仍可能需要联网，不保证所有功能首次加载后立即完全离线。

**图标没变化？** 浏览器或主屏幕可能有缓存。刷新网站；已安装的主屏幕快捷方式必要时删除后重新添加。
